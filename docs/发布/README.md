## 使用建议

- 新版本发布时新增 `v<版本号>-变更记录.md` 并在上面登记一行，不要往旧记录里追加新版本的内容。
- 打包流程变化时同步更新记录里的第五节，避免文档与 `build-app.sh` 说法不一致。
