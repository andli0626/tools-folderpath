## 一、需求与结论

**需求**：悬浮按钮应支持「设置是否开启」与「自己手动关闭」。

**结论**：v1.2.0 已提供托盘菜单「悬浮按钮」勾选项（设置开关）与右键菜单「隐藏悬浮按钮」
（手动关闭），但两者都不够直观——托盘菜单藏在菜单栏图标里，右键菜单需要知道右键在哪。
v1.2.1 在胶囊右侧常驻一枚「×」关闭钮，点一下即隐藏并落盘，是「自己手动关闭」最
直接的入口。

**设计选择（方案 B：胶囊内常驻 ×）**：

| 候选 | 做法 | 取舍 |
| --- | --- | --- |
| **B（采纳）** | 胶囊右侧画 ×  glyph，点击区 16pt，与文字区间隔 5pt | 零学习成本、不依赖 hover、不改变位置语义；胶囊宽度 +10pt |
| A（否决）| hover 时浮现 × 徽章 | 需要 tracking area、hover 状态机、动画；触摸板用户难以触发 |
| C（否决）| 双击关闭 | 与单击复制冲突，语义模糊 |

## 二、逐文件修改明细

### 2.1 `src-tauri/src/float_button.rs`（+38 行，本版本主体）

- **新增常量**：`CLOSE_GAP = 5.0`（× 与文字间距）、`CLOSE_ZONE = 16.0`（× 点击区
  宽度）、`CLOSE_PAD_R = 2.0`（× 距胶囊右缘内边距）。胶囊宽度公式加入这三项。
- **新增 ivar**：`down_in_close: Cell<bool>`——mouseDown 时记录是否落在 × 区。
- **drawRect**：在胶囊右部画 × glyph（两条白色 0.55 alpha 线段，lineWidth 1.6，
  `NSLineCapStyle::Round` 端点），圆心位于 `width - CLOSE_PAD_R - CLOSE_ZONE/2.0`。
- **mouseDown**：若 `point.x >= width - CLOSE_ZONE - CLOSE_PAD_R` 则置
  `down_in_close = true`，不进入拖动流程。
- **mouseDragged**：`down_in_close` 为真时早退——× 区内按下不触发拖动。
- **mouseUp**：`down_in_close` 为真时调 `hide_and_disable(&ivars.app)`（隐藏面板 +
  落盘 `enabled=false`），不触发复制。

## 三、关键设计决定

### 3.1 × 区禁止拖动

× 区按下时 `mouseDragged` 直接早退，避免「想关按钮却拖动了窗口」的误操作。× 区
宽度 16pt 足够命中，又不会让文字区损失太多可拖面积。

### 3.2 × 关闭 = 落盘关闭

× 点击调 `hide_and_disable`，与右键「隐藏悬浮按钮」完全同路径：面板隐藏 +
`float-button.json` 写入 `enabled=false`。下次启动不会自动显示，除非用户通过
托盘菜单重新勾选。

### 3.3 三条关闭/开关路径

| 入口 | 位置 | 效果 |
| --- | --- | --- |
| × 关闭钮 | 胶囊右侧 | 隐藏 + 落盘 `enabled=false` |
| 右键「隐藏悬浮按钮」 | 悬浮按钮右键菜单 | 同上 |
| 托盘「悬浮按钮」勾选 | 菜单栏图标 → 悬浮按钮 | 切换显示/隐藏，落盘 |

## 四、交互时序

```
左键点 × 区 → mouseDown(down_in_close=true) → mouseDragged 早退
  → mouseUp → hide_and_disable → 面板隐藏 + float-button.json enabled=false
左键点文字/图标区 → mouseDown → mouseUp → fetch_and_copy(ItemPath)（不变）
拖动文字/图标区 → mouseDragged → setFrameOrigin → mouseUp 落盘位置（不变）
```
