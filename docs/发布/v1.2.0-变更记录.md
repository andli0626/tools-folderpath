# v1.2.0 变更记录

本文是**带版本的交付记录**，详细总结 v1.2.0 的全部修改内容：新增「屏幕悬浮按钮」
（非激活 NSPanel，点击默认执行「复制选中项自身路径」）。当前用法与故障排查请看根目录
[README.md](../../README.md)。

- 版本：1.2.0（从 1.1.5 升上来）
- 日期：2026-10-06
- 代码量：9 个文件修改 `+140 / -18`（`git diff --stat` 实测，含 Cargo.lock）；
  新增 `src-tauri/src/float_button.rs`（489 行）与本变更记录

## 一、需求与结论

**需求**：增加全局悬浮按钮，点击默认执行「复制选中项自身路径」。

**可行性结论**：可行，关键约束是**点击不得改变前置应用**。悬浮按钮若用普通 NSWindow
（或 Tauri 窗口），点击必然激活 CopyPath，Finder 失去前置身份，「选中项 / 前置窗口」的
解析语义随之被破坏。macOS 对此的现成答案是 `NSPanel` + `NonactivatingPanel` 掩码：
点击面板不激活归属应用，Finder 保持前置，`finder::resolve` 读到的选中项与托盘菜单
语义完全一致。

**架构选择（方案 A：主程序内直接建 AppKit 面板）**：

| 候选 | 做法 | 取舍 |
| --- | --- | --- |
| **A（采纳）** | 主程序用 objc2 直接建非激活 NSPanel，事件在 Rust 里处理 | 不抢焦点、无 WebView 进程、复用 `fetch_and_copy`（进历史、有重入保护）；代价：引入 objc2 三件套依赖，手写 AppKit 粘合 |
| B（否决） | Tauri WebviewWindow 常驻悬浮页 | NSWindow 点击必激活自身（需要 hack 才能 non-activating），且为一个按钮拉起整个 WKWebView 进程 |
| C（否决） | 复制 Toolbar helper 模式再做一个独立 .app | 「复制选中项自身路径」要读选中项，helper 每次冷启 + 退出可以做到，但托盘开关、位置记忆、历史写入都要跨进程，复杂度高于收益 |

objc2 版本锁在 `objc2 0.6 + objc2-app-kit 0.3 + objc2-foundation 0.3`：与 tao/wry/muda
在 Cargo.lock 里已有的版本同区间，不引入第二套 objc 运行时。

## 二、逐文件修改明细

### 2.1 `src-tauri/src/float_button.rs`（新增，本版本主体）

- **面板**：`NSPanel` + `Borderless | NonactivatingPanel` 掩码，level =
  `NSFloatingWindowLevel(3)`，collectionBehavior =
  `CanJoinAllSpaces | FullScreenAuxiliary | IgnoresCycle`（所有空间、全屏应用之上可见），
  `setHidesOnDeactivate(false)`（NSPanel 默认随失活隐藏，必须显式关掉），
  透明背景 + 胶囊自绘（`drawRect` 里 `NSBezierPath` 圆角矩形，深色半透明 HUD 造型）。
- **视图类**：`define_class!` 定义 `CopyPathFloatButtonView`（NSView 子类）：
  - `hitTest:` 恒返回自身——图标/文字子视图纯展示，整块可点可拖；
  - `mouseDown/mouseDragged/mouseUp`：位移超过 4px 记为拖动，直接 `setFrameOrigin`
    跟手挪窗口（不用 `performWindowDrag` 的模态循环，松手时 `frameOrigin` 即最终位置）；
    未拖动则 `mouseUp` 触发 `fetch_and_copy(ItemPath)`——与托盘「复制选中项自身路径」
    同一条代码路径，含最近历史写入与重入保护；
  - `rightMouseDown:` 弹小菜单：两种复制语义 + 「隐藏悬浮按钮」，target 指向自身；
  - ivars 持有 `AppHandle`（`define_class!` 自动生成 dealloc 释放 ivars）。
- **位置记忆**：落盘的是窗口**左上角**（NSWindow 的 origin 是左下角，换算与屏幕高度
  无关）；还原时与任一屏幕 `visibleFrame` 求交，无交集（拔外接屏、改分辨率）回落
  默认位置（主屏右缘居中）。宽度按 NSTextField `sizeToFit` 的实际渲染宽度收口。
- **设置**：`float-button.json`（`{enabled, pos}`，包一层对象防格式迁移），无文件/
  文件损坏时默认 `enabled=true`。`load` 是 pub（lib.rs 启动时读），其余收在模块内。

## 三、关键设计决定

### 3.1 点击不改前置（NonactivatingPanel）

这是整个功能成立的前提：悬浮按钮点了之后 Finder 仍是前置应用、选中项不丢，
`finder.rs` 一行不用改。顺带省掉了「菜单栏左键不能一键复制」的历史遗憾——
一键复制现在有悬浮按钮这个入口（快捷键依然保留）。

### 3.2 悬浮按钮进历史，Toolbar helper 不进

历史文件与托盘子菜单联动是常驻应用的运行时状态（`history::push` 需要 `AppHandle`）。
悬浮按钮跑在主程序里，天然有这些设施，行为与托盘菜单一致；一次性 helper 维持不进
历史的取舍不变（见 v1.1.5 记录 3.3）。

### 3.3 不用 WebView、不建 Tauri 窗口

`tauri.conf.json` 的 `windows` 仍为空数组。悬浮按钮是纯 AppKit 面板，不引入
WKWebView 进程，内存占用与 v1.1.5 同量级；代价是手写 objc2 粘合（约 400 行）。

## 四、交互时序

```
左键点悬浮按钮 →（NonactivatingPanel，不激活 CopyPath，Finder 仍前置）
  → mouseUp → fetch_and_copy(ItemPath) → 子线程跑 osascript 读选中项
  → 主线程收尾：写剪贴板 → 原生通知 → 最近路径历史置顶
右键 → 弹语义菜单（Finder 仍前置）→ 菜单项动作同上 / 隐藏面板 + 落盘
拖动 → mouseDragged 按位移 setFrameOrigin → mouseUp 落盘左上角坐标
```

## 六、遗留与限制

- 悬浮按钮是常驻窗口，需要整块屏幕时用托盘菜单或右键菜单「隐藏悬浮按钮」。
- 运行中把按钮拖出屏幕边缘不会自动拉回（启动还原失败才会回落默认位置）。
- 无独立快捷键、无设置界面；语义切换靠右键菜单。
- 真人点击验证待用户完成（见第五节末行）。
