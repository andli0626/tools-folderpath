## 一、问题报告与真因

**症状**：悬浮按钮不显示；进一步观察发现整个应用启动后既无托盘图标也无按钮，
且无任何用户可见报错。

**真因（缺陷 1，崩溃）**：`mouseExited:` 的 Rust 方法签名与 ObjC selector 参数
个数不符——selector 收 1 个 `NSEvent`，代码写成零参。objc2 0.6 的 `define_class!`
**编译期不检查参数个数**，在运行时类注册阶段才 `assert`
（`selector mouseExited: accepts 1 arguments, but function accepts 0`）。该 panic
落在 AppKit 不可 unwind 的回调（`did_finish_launching`）里，进程直接 abort。
表现就是"什么都没发生"：视图类注册失败 → 面板永远建不出来 → 用户看到的功能缺失
其实是**整个应用启动即崩**。

**定位方式**：前台跑裸二进制看 stderr，崩溃行第一句就是答案。

## 二、逐条缺陷明细

### 缺陷 1 · 启动即 abort（悬浮按钮不显示）

- 位置：`float_button.rs:664`
- 修复：`mouseExited:` 补上 `_event: &NSEvent` 参数，与 `mouseMoved:` 同款写法。
- 注意：`#[unsafe(method_id(...))]` 形式要求显式返回类型且不接受 `-> ()`
  （`MaybeOptionRetained` 约束），带参无返回值的方法用 `#[unsafe(method(...))]`。

### 缺陷 2 · 按下高亮永久卡住

- 位置：`float_button.rs:501`（`down_zone`）、`:716`（`mouseUp` 复位）
- 症状：`drawRect` 的 `pressed` 判定是 `down_zone != -1`，但 `down_zone` 原为
  `Cell<Zone>`（枚举无 -1），且 `mouseUp` 从不复位——点过一次某段后，
  该段永远停在按下高亮态，直到下一次别处按下。
- 修复：`down_zone` 改 `Cell<i8>`（-1 = 未按下），`mouseUp` 用
  `replace(-1)` 先复位再分发；新增 `Zone::from_i8`（`:83`）做无损还原，
  配单测 `zone_roundtrips_through_i8`。

### 缺陷 3 · drawRect 里 addSubview，图标子视图无限累积

- 位置：`float_button.rs:504`（常驻图标槽）、`:629`（drawRect 只换图）、
  `:858`（`symbol_image` 辅助函数）
- 症状：每帧 `drawRect` 都 `addSubview` 一对新 `NSImageView` 且从不移除；
  hover、flash 任一重绘都让子视图数量 +2，内存与绘制成本随点击持续增长。
- 修复：两段图标改在 `create_panel` 里常驻创建一次，存入 ivars 的
  `RefCell<Option<Retained<NSImageView>>>`；`drawRect` 只 `setImage` +
  `setContentTintColor`。
- 顺带口径修正：文件夹段确认态图标原为 `folder.fill`，与注释「成功确认态换成 ✓」
  矛盾，统一为 `checkmark`。

### 缺陷 4 · Vibrancy 档（macOS 12–15）按钮内容整体不可见

- 位置：`float_button.rs:326-327`、`:369-370`（`view_frame` 零基坐标）
- 症状：`FloatButtonView` 用**屏幕坐标的窗口 frame** 作视图 frame 初始化。
  L2 材质走 `fx.addSubview(view)`，`addSubview` 不重摆子视图位置，内容整体落在
  材质视图 bounds 之外——macOS 12–15 用户只能看到一块空材质。当前 macOS 27 走
  L1 `NSGlassEffectView.setContentView` 被钉回 bounds 才侥幸正常；L3 走
  `panel.setContentView` 同理。
- 修复：视图与材质容器统一改用零基 `view_frame`（origin (0,0)、尺寸同胶囊）。
  `minimumSystemVersion` 是 12.0，这条修的是受支持路径。

### 杂项

- 删除 `frame_at_rejects_positions_off_every_screen` 里复制粘贴出的重复断言行。
- `Zone` 头注释「分隔线归入左侧可拖区」与代码相反（`zone_at` 左闭右开，
  `b[1]` 起是文件段），改为与实现一致。
