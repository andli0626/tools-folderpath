## 一、需求与结论

**需求**：参考 go2claude 的 `Go2Claude Toolbar.app` 模式，支持把一个 app 拖到访达工具栏，
点击后立刻把当前文件夹路径复制进剪贴板。

**可行性结论**：可行，且交互模式在同机器的 Go2Claude 上已长期验证——无界面（LSUIElement）
小 app 被点击时由 LaunchServices 启动，因为不抢焦点，Finder 仍是前置应用，AppleScript 读
「前置窗口目标」拿到的就是触发它的那个窗口。

**架构选择（方案 A：helper 自包含）**：

| 候选 | 做法 | 取舍 |
| --- | --- | --- |
| **A（采纳）** | helper 自己跑 osascript → 写剪贴板 → 通知 → 退出 | 点击**无条件有结果**，不依赖主程序在跑；代价：独立 bundle id 需单独授权一次，逻辑与主程序同源复用（见 2.1） |
| B（否决） | helper 发通知，常驻托盘进程干活 | 可复用已授权与历史写入，但点击结果取决于主程序是否存活，跨进程 IPC 复杂度高于收益 |

单实例锁不构成冲突：helper 是独立二进制 `copypath-toolbar`，不碰 `instance.lock`、不建托盘。

## 二、逐文件修改明细

### 2.1 `src-tauri/src/lib.rs`（+67/-42 中的主体）

- `mod notify` 改为 `pub mod notify`（helper 入口需要 `set_bundle`）。
- 从 `finish()` 里抽出 **`copy_and_notify(paths, wait_notify)`**：拼接多行路径 → 写剪贴板 →
  按数量发「已复制路径 / 已复制 N 个路径」通知。快捷键、托盘菜单与工具栏 helper 三条入口
  共用这一份语义，保证行为不会分叉。
- 新增 **`pub fn toolbar_copy()`**：`finder::resolve(FolderPath)` → `copy_and_notify(paths, true)`，
  成功返回 0；失败发通知 + stderr 打日志并返回 1。**刻意不写「最近路径」历史**（见 3.3）。
- `finish()` 改为调用 `copy_and_notify(&paths, false)`，行为与 v1.0.0 完全一致。

### 2.2 `src-tauri/src/notify.rs`

- 拆出 `build(title, body)` 组装函数，`show()` 行为不变（独立线程，防 mac-notification-sys
  挂死主线程的历史问题）。
- 新增 **`show_and_wait()`**：同步阻塞发通知。helper 是点完即退的一次性进程，异步线程还没
  发出去 `process::exit` 就把通知整条丢了——这是本轮踩出来的一条硬约束。

### 2.3 `src-tauri/src/toolbar_main.rs`（新增）

helper 入口，全文 9 行：设通知归属 bundle id → `toolbar_copy()` → 按其返回值退出。

  会关闭 `src/main.rs` 的自动发现，所以两个都必须写全，已留注释说明。

## 三、关键设计决定

### 3.1 逻辑零复制

helper 不重写任何路径解析：`finder.rs` 的 AppleScript、`parse()` 的选中项归一化语义
（选文件夹取自身、选文件取所在目录、多选去重成行）与主程序逐字节同一份代码，
12 个既有单测全部继续覆盖 helper 的行为。

### 3.2 通知必须同步发

见 2.2。成功与失败路径都走 `show_and_wait`。

### 3.3 刻意不进「最近路径」

历史文件与托盘子菜单联动是常驻应用的运行时状态（`history::push` 需要 `AppHandle` 刷菜单），
一次性 helper 为写一条 JSON 去起半个 tauri 不值当。已登记进 README「已知限制」。

## 四、点击时序

```
点工具栏按钮 → LaunchServices 启动 helper（LSUIElement，无 Dock、不抢焦点）
  → Finder 仍是前置应用 → copypath-toolbar 跑 finder::resolve(FolderPath)
  → 写剪贴板 → show_and_wait 通知 → 进程退出（.app 共 744K，冷启动 <1s）
```

## 六、遗留与限制

- helper 只覆盖「立即获取文件夹路径」一种语义，无「复制选中项自身路径」入口，不进最近历史。
- 独立 bundle id：首次点击授权一次；ad-hoc 重打包会使该授权失效，重置命令见 README 故障排查。
- ⌘+拖拽安装无法自动化（Computer Use 的 drag 不支持全程按住修饰键），换机部署需真人操作一次。
