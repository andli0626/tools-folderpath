# v1.3.0 变更记录

本文是**带版本的交付记录**，总结 v1.3.0 的全部修改：悬浮按钮从「一枚只有一种语义的
胶囊」改成「三段分段控件」（左段复制文件夹路径、中段复制文件路径、右端 × 关闭），
容器材质换成 macOS 26+ 的原生 Liquid Glass。当前用法见根目录 [README.md](../../README.md)。

- 版本：1.3.0（从 1.2.1 升上来）
- 日期：2026-10-06
- 核心改动：`src-tauri/src/float_button.rs`、`src-tauri/src/finder.rs`

配套文档：[技术方案](../核心功能/悬浮按钮-双语义与视觉重构-技术方案.md)、
[视觉稿](../核心功能/悬浮按钮-视觉稿.html)、

## 一、需求与结论

**需求**：悬浮按钮要「美化」，并增加两个点击——一个复制文件夹路径，一个复制文件路径。

**结论**：按钮改成三段分段控件（左「文件夹」/ 右「文件」/ 右端「×」）。
但本次的真正主因不是加按钮，而是**换材质**：1.2.1 的手绘 `white @ 0.10` 胶囊在浅色
背景上对比度只有 **1.2:1**，等于隐形——这是**已存在的缺陷**，不是新需求带来的。

## 二、三个设计决定

| 决定 | 取舍 | 理由 |
| --- | --- | --- |
| 选中文件夹点「文件」段 | 回退当前窗口目录 | 不复用 `ItemPath`——那个模式选中文件夹时返回的就是文件夹路径，拿它当「文件」段会让**标签在说谎** |
| L1 交互反馈 | 交给玻璃，保留手写兜底 | `effectIsInteractive` 的 KVC **可能静默失败**，故手写三态始终生效 |
| L3 降级配色 | 深色实底，不用现状白半透明 | 照抄 `white @ .10` 等于把 1.2:1 的缺陷带进降级路径，只是换了个系统版本 |

## 三、逐文件修改明细

### 3.1 `src-tauri/src/finder.rs`

- `Mode` 新增 `FilePath`：只取 `kind == 'F'` 的记录（脚本**已输出**该标志位，
  不碰 AppleScript、不碰权限）；选中里没有文件时回退 `container_path`。
- `parse` 加对应分支；新增 5 个单测覆盖语义表全部状态。

### 3.2 `src-tauri/src/float_button.rs`

- **常量重排**：HEIGHT 34→36、ICON 15→14、RADIUS 10（原 `height/2` 全胶囊）、
  新增 `SEG_PAD_R` / `DIVIDER_W=0.5` / `DIVIDER_INSET=10`。
- **三级材质降级**：`material_tier()` 按**类存在性**判定
  （`AnyClass::get(c"NSGlassEffectView")`），不用版本号比较——后者要维护白名单，
  且对未来大版本失效。L1 `NSGlassEffectView` / L2 `NSVisualEffectView`+`.hudWindow`
  / L3 手绘深色实底。
- **三段命中区**：`zone_at(x)` 纯函数替换原 `down_in_close` 布尔。
  `capsule_width()` 与 `zone_bounds()` **合并为单一来源**，避免「画的宽」与
  「判的宽」漂移。
- **flash 确认态**：点击后该段图标换 `checkmark` + 泛绿，700ms 后由一次性
  `NSTimer` 复原。block 捕获 `Retained` 强引用与视图同生共死，**不用裸指针**
  （裸指针在视图释放后即野指针）。
- **hover tracking area**：仅装饰，功能全在常驻段上。
- **`frame_at` 夹紧**：原逻辑只判「相交」，按钮加宽到 163pt 后停在屏缘的位置会
  **整块跑到屏外**，相交为 false 就掉回默认位置。改为**按左上角归属 + 夹紧**。
- L1 下 `drawRect` **不画圆角**（玻璃自带 `cornerRadius` 且会折射裁切，叠加会
  切断边缘高光）。

### 3.3 其他

- `Cargo.toml`：features 加 `NSGlassEffectView` / `NSVisualEffectView` /
  `NSTrackingArea`；`objc2-foundation` 显式开 `NSTimer` 等；新增 `block2`
  （`NSTimer` block 签名的硬依赖）。版本 1.3.0。
- `lib.rs`：`--probe file` 新增。
- `tauri.conf.json`：版本 1.3.0。**`minimumSystemVersion` 保持 12.0 未动**——
  改成 26 会让 12–25 的用户装不上。

## 四、过程中修掉的三个自身缺陷

1. **宽度公式与分区各算各的**，差 0.5pt（「画出来的宽」与「判定用的宽」漂移）。
   已合并为单一来源，并加 `capsule_width_equals_the_last_boundary` 锁死不变量。
2. **`file_mode` 回退取错字段**：取了 `item_path`（等于文件夹自身），
   应取 `container_path`。被 `file_mode_never_returns_a_selected_folder_itself` 抓出。
3. **删除不成立的测试时正则贪婪匹配吃掉后续 3 条**。**单测全绿时改用 `git diff`
   对比函数清单确认零丢失**，而不是相信绿灯。

## 六、待验证（代码无法覆盖）

代码跑绿**不等于**视觉达标。以下必须真机确认，走查清单里是 W-45~W-48、W-50~W-54：

- **W-45/47** Liquid Glass 的折射与边缘高光是否真的渲染出来了
- **W-46** `effectIsInteractive` 的 KVC 是否生效（**当前 objc2 绑定未收录该属性，
  27.0 才发布，可能静默失败**）；失败时手写三态会顶上
- **W-48** 玻璃视觉上「浮起来」，极易顺手把面板做大留投影余量——那会**吃掉下面
  应用的点击**。面板必须严格等于可见胶囊
- **W-50~W-54** L1/L2/L3 三档的实际观感与行为一致性
