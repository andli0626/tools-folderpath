核心功能

四种触发，总有一种顺手

同一个动作——把"当前文件夹路径"送进剪贴板——四个入口，覆盖你不同的肌肉记忆。

⌃⌥⌘P

全局快捷键

任何应用里按下，立即复制访达当前窗口/所选项目的所在目录。手不用离开键盘。

☰

菜单栏托盘

「立即获取文件夹路径」「复制选中项自身路径」两条菜单，外加最近 10 条路径历史，点一条即复制。

✦v1.1.5 新增

访达工具栏按钮

把 CopyPath Toolbar 拖进访达工具栏，在任意文件夹点一下按钮即复制。不依赖主程序运行，即点即用即走。

◉v1.2.0 新增

屏幕悬浮按钮

常驻屏幕的小胶囊：点一下复制「选中项自身路径」，按住拖到顺手的位置；右侧 × 一键关闭，右键切换语义。点击不抢 Finder 焦点。

路径语义

复制的永远是"你以为的那个路径"

选中项优先、无选中回退窗口目录；同目录多个文件自动去重成一行。屏幕悬浮按钮左键固定执行右列语义，右键可临时切换两种语义。规则可预期，从不猜。

访达里的状态「立即获取文件夹路径」/ 快捷键 / 工具栏按钮 / 悬浮按钮右键「复制选中项自身路径」/ 悬浮按钮左键
无选中项当前窗口目录 /Users/dev/Projects/app当前窗口目录
选中 1 个文件夹该文件夹自身 …/app/src该文件夹自身
选中 1 个文件它所在的目录 …/app/src该文件自身 …/src/main.rs
同目录下选中 3 个文件该目录，去重成 1 行3 行，每行一个
一个访达窗口都没开明确报错，不动剪贴板——绝不静默给你一个桌面路径
安装指南

3 分钟装好

两种入口任选：拿到 dmg 直接拖，或者从源码一行命令打包。

获取应用

双击挂载 CopyPath_1.2.1_universal.dmg，把卷里的 CopyPath.app（想要工具栏按钮就把 CopyPath Toolbar.app 也带上）拖进 应用程序 文件夹。

# 或者：从源码打包（自动产出 .app 与 .dmg 并安装启动）
# 开源仓库：http://192.168.0.200/lil/tools-folderpath
git clone http://192.168.0.200/lil/tools-folderpath
cd tools-folderpath && ./build-app.sh

首次运行

打开 CopyPath.app，菜单栏出现图标即成功，屏幕右缘同时出现悬浮小按钮（不想用就点胶囊右侧的 × ，或托盘菜单里的「悬浮按钮」开关）。第一次触发复制时系统会请求「控制访达」的自动化权限，点允许即可（仅一次）。

装访达工具栏按钮（可选，v1.1.5）

在访达里选中 CopyPath Toolbar.app，按住 ⌘ 键把它拖到窗口顶部工具栏，看到插入位后松手。之后每个访达窗口都有了这枚按钮。

验证

打开任意文件夹 → 按 ⌃⌥⌘P 或点工具栏按钮 → 右上角弹出「已复制路径」→ 到任何输入框 ⌘V，路径就在里面。

※ 本机生成的 dmg 不带隔离属性，双击即开；经浏览器下载转到其他机器被 Gatekeeper 拦时，右键 → 打开 → 再点一次「打开」。

常见问题

遇到问题先看这里

报 -1743 或「未获得授权」怎么办？
应用为 ad-hoc 签名，重新打包会使旧的自动化授权失效。重置后重新触发一次并点允许：

tccutil reset AppleEvents com.lilin.folderpath
tccutil reset AppleEvents com.lilin.folderpath.toolbar（工具栏按钮是独立授权）
快捷键按了没反应？
可能被其他应用占用。注册失败时应用只降级不报错，托盘菜单与工具栏按钮仍然可用。也可在「系统设置 → 键盘 → 键盘快捷键」里排查冲突。
工具栏按钮点了没反应？
按钮记录的是"拖入那一刻 .app 所在的路径"。升级或移动过 CopyPath Toolbar.app 后，把旧按钮按住 ⌘ 拖出工具栏，再重新拖入新的即可。
它会把我的路径传到网上吗？
不会。CopyPath 完全离线：读路径用本机 AppleScript，结果只进系统剪贴板和本机历史文件（~/Library/Application Support/com.lilin.folderpath/history.json），无任何网络请求。
工具栏按钮和快捷键行为一样吗？
路径语义完全一致（含多选去重）。两点差异：工具栏按钮不写「最近路径」历史，也没有「复制选中项自身路径」入口——那两项走托盘菜单。
屏幕上的悬浮小按钮是什么？怎么关掉？
v1.2.0 新增：左键点击即复制「选中项自身路径」，按住可拖动位置，右键弹出菜单切换两种语义。关闭方式任选：点胶囊右侧的 ×（v1.2.1 起）、右键菜单「隐藏悬浮按钮」、或托盘菜单的「悬浮按钮」开关。开关与位置都会被记住（~/Library/Application Support/com.lilin.folderpath/float-button.json），托盘里随时再打开。点击它不会抢走访达的前置焦点。
