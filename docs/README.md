# CopyPath 文档中心

菜单栏小工具，把访达当前窗口或所选项目的绝对路径一键写进剪贴板。Rust + Tauri v2，无前端界面。

开源地址：<http://192.168.0.200/lil/tools-folderpath>

## 发布

- [v1.3.0 变更记录](./发布/v1.3.0-变更记录.md) —— 悬浮按钮改三段分段控件（文件夹/文件/×），材质升级 Liquid Glass 三级降级
- [v1.3.0 缺陷修复记录](./发布/v1.3.0-缺陷修复记录.md) —— 悬浮按钮不显示真因（启动即崩）与按下态卡死、图标累积泄漏、Vibrancy 档内容不可见
