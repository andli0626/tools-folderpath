# 访达工具栏按钮 · 安装指南

> 面向使用者的安装文档：把 **CopyPath Toolbar.app** 装进访达工具栏，实现「点一下按钮，
> 复制当前文件夹路径」。功能原理与限制见
> [实现技术方案](./访达工具栏按钮-实现技术方案.md)。

## 1. 系统要求

- macOS 12.0 及以上（Apple Silicon / Intel 均可，产物为 universal）
- 无需安装任何运行时；两个 .app 均为独立包

## 2. 获取安装包

**方式一：本机源码打包**（在仓库根目录）

```bash
./build-app.sh
```

产出并自动完成：

- `~/Downloads/CopyPath_1.1.5_universal.dmg`（分发用镜像）
- `~/Applications/CopyPath.app`（常驻托盘主程序，自动启动）
- `~/Applications/CopyPath Toolbar.app`（工具栏按钮 helper，**不需要启动它**，装好待拖即可）

**方式二：使用现成 dmg**

双击挂载 `CopyPath_1.1.5_universal.dmg`，卷内有三个项目：

```
CopyPath.app            ← 拖到 Applications（建议，主程序）
CopyPath Toolbar.app    ← 也拖到 Applications，然后进行第 3 步
Applications → /Applications 软链接
```

> **重要：两个 .app 都要装进内部磁盘的 `/Applications` 或 `~/Applications`，
> 不要停留在挂载卷或外置盘上再拖** —— 工具栏按钮记录的是"拖入那一刻的 .app 路径"，
> 源路径消失（弹出 dmg、拔掉外置盘）后按钮会点击无反应。

本机自产的 dmg 不带隔离属性，双击即开；若经浏览器下载/隔空投送转到别的机器被
Gatekeeper 拦，用「右键 → 打开 → 再点一次打开」放行。

## 3. 拖入访达工具栏（一次性，需真人操作）

1. 打开访达，进入 `~/Applications`（或 `/Applications`，看你装在哪）。
2. 找到 **CopyPath Toolbar.app**。
3. **按住 <kbd>⌘</kbd> 键**，把它拖到访达窗口顶部的工具栏上，看到插入位指示后松手。
   - 放哪个位置都行，按钮会常驻工具栏，对所有访达窗口生效。
   - 不带 ⌘ 直接拖会被工具栏拒收，这是 macOS 的限制。
   - 工具栏已满时，可先右键工具栏 →「自定工具栏…」清理，或把窗口拉宽。

## 4. 首次授权（一次性）

第一次点击工具栏按钮时，macOS 会弹窗：

> “CopyPath Toolbar”希望控制“访达”。

点**允许**。这是独立于主程序的一次授权（bundle id 为
`com.lilin.folderpath.toolbar`）。如当时误点拒绝，去
**系统设置 → 隐私与安全性 → 自动化 → CopyPath Toolbar → 打开「访达」**补授权。

## 5. 验证是否装好

1. 在访达打开任意文件夹（比如「下载」）。
2. 点一下工具栏上的 CopyPath 按钮。
3. 预期：右上角弹出「已复制路径」通知，短暂图标闪动后无驻留进程。
4. 在任意输入框 ⌘V 粘贴，应得到该文件夹的绝对路径（如 `/Users/你的用户名/Downloads`）。

也可以开终端做严格对照：

```bash
printf 'SENTINEL' | pbcopy     # 先放一个哨兵值
# ……点一下工具栏按钮……
pbpaste                        # 应显示当前文件夹路径，而不是 SENTINEL
```

**行为语义**（与主程序「立即获取文件夹路径」一致）：

| 点击时访达状态 | 复制结果 |
| --- | --- |
| 无选中项 | 当前窗口目录 |
| 选中 1 个文件夹 | 该文件夹自身 |
| 选中 1 个文件 | 它所在的目录 |
| 多选 | 每目录一行，自动去重 |
| 一个访达窗口都没开 | 失败提示，**不动剪贴板** |

## 6. 升级

重新跑一次 `./build-app.sh`（或安装新 dmg）即可：脚本会原地替换
`~/Applications/CopyPath Toolbar.app`，工具栏按钮通常自动跟到新包。

升级后若出现以下情况，按对应处理：

| 现象 | 处理 |
| --- | --- |
| 点击无反应 | 按钮绑定的旧路径已失效：把工具栏上的旧按钮按住 ⌘ 拖出删掉，重新执行第 3 步 |
| 报 -1743 /「未获得授权」 | ad-hoc 重签名使旧授权失效：`tccutil reset AppleEvents com.lilin.folderpath.toolbar` 后重新点击并允许 |

## 7. 卸载

1. 按住 <kbd>⌘</kbd> 把工具栏上的按钮拖离工具栏，松手即删除。
2. 删除 `~/Applications/CopyPath Toolbar.app`（或 `/Applications` 下的对应文件）。
3. （可选）清掉授权记录：`tccutil reset AppleEvents com.lilin.folderpath.toolbar`。

helper 无数据文件、无自启动项，删掉 .app 即彻底卸载；主程序 CopyPath.app 不受影响。

## 8. 常见问题

**点了按钮没通知？**
剪贴板可能其实已复制成功（通知只是反馈）。先 ⌘V 验证；若确实没复制，检查第 4 步授权。

**复制到的不是我以为的"当前文件夹"？**
按钮以**点击瞬间的最前台访达窗口**为准。多窗口/多标签时，先点一下目标窗口再按按钮；
分栏视图下以路径栏最右端为准。

**能用它复制"选中文件自身"的路径吗？**
不能，工具栏按钮只有「所在文件夹」一种语义；需要选中项自身路径请用主程序托盘菜单的
「复制选中项自身路径」。

**点击结果会进主程序的「最近路径」吗？**
不会（设计决定，见技术方案 5.7）。需要历史记录就走快捷键或托盘菜单。
